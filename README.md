# Cult Of Hela

## Français
Ce jeu a été fait durant ma 2eme et ma 3eme année d'étude.
Cult of Hela est un Diablo Like (Dungeon Crawler / RPG), l'idée venait d'un simple exercice pour se déplacer sur Unity avec un click droit comme de nombreux jeux en vu Isométrique. 
Je voulais également m'entrainer sur ces éléments :
  3C
  UI
  IA
  GPE
  Animation
  Tools
