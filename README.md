# Cult Of Hela

## Français
Ce jeu a été fait durant ma 2ème et ma 3ème année d'étude.
Cult of Hela est un Diablo Like (Dungeon Crawler / RPG), l'idée venait d'un simple exercice pour se déplacer sur Unity avec un clic droit comme de nombreux jeux en vue isométrique.
Je voulais également m'entraîner sur ces éléments :
  3C
  UI
  IA
  GPE
  Animation
  Tools

## English
This game was made during my 2nd and 3rd years in programming school.
Cult of Hela is a Diablo like (Dungeon Crawler / RPG), the idea came from a simple exercise to learn how to move a character in Unity from a right click like many games in Isometric view.
I also wanted to learn about :
  3C
  UI
  IA
  GPE
  Animation
  Tools
